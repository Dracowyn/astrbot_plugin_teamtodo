# 协作 TODO（astrbot_plugin_teamtodo）

面向单人和群聊的协作 TODO 插件，运行在 AstrBot 上。在群里用 `/todo` 指令创建和推进任务，让机器人在对话中帮忙管理任务，并在截止前提醒负责人。

## 功能

- 任务卡片与看板：标题、负责人、截止时间、优先级、标签、描述、状态（待办 / 进行中 / 已完成 / 已归档）。
- 空间：任务的容器，可以绑定到多个群或私聊，多个群共享同一份任务。
- `/todo` 指令：增删改查任务，切换和管理空间。
- LLM 对话管理：通过自然语言创建、查询和修改任务。
- 到期提醒与指派通知：截止前提醒负责人，新增负责人时在群里 @ 对方。
- WebUI 管理页：在 AstrBot 管理页面里查看和管理所有空间。
- 公开只读看板：空间管理员可以生成一个公开链接，任何拿到链接的人无需登录即可只读查看看板。

## 安装

需要 AstrBot 4.29 及以上（5.0 以下）。在 AstrBot WebUI 的插件页面通过仓库链接安装，或上传插件压缩包。安装后确认插件已启用，并按需修改配置项（见下文“配置项”）。

## 快速上手

在群里发送以下指令。`#3` 是任务编号，每个空间内从 1 开始递增。

```
/todo add 整理活动报名表 @张三 11-05 18:00 !高 [活动]
/todo list
/todo done #3
/todo assign #3 @张三 @李四
/todo mine
```

第一次在群里使用 `/todo` 时，插件会自动为这个群创建一个默认空间。

## 核心概念

**空间**：任务的容器。一个群可以绑定多个空间，一个空间也可以被多个群或私聊绑定。

**当前空间**：每个人在每个群里各有一个当前空间，用 `/todo use <空间名>` 切换，只影响自己。没有切换过的人使用群的默认空间。

**成员**：在绑定的群或私聊里用过 `/todo`、或被 @ 指派过的人，自动成为空间成员。只能把任务指派给空间成员。

**角色**：

| 角色 | 主要权限 |
|---|---|
| 所有者 | 全部权限，包括任命或撤销管理员、删除空间 |
| 管理员 | 修改或删除他人的任务，生成邀请码，重命名空间 |
| 成员 | 创建任务，修改自己创建或负责的任务，改变其状态 |

AstrBot 管理员在所有空间中都拥有全部权限。群主和群管理员可以执行 `join`、`leave`、`default`、`claim` 等会话层面的操作。

## 指令速查

所有指令以 `/todo` 开头。发送单独的 `/todo` 或 `/todo help` 可以查看帮助。

`<ref>` 指任务引用，写作 `#3`、`3`，或跨空间写作 `空间名#3`（只能引用本群绑定的空间）。

**任务指令**

| 指令 | 说明 |
|---|---|
| `/todo add <字段…>` | 在当前空间创建任务 |
| `/todo list [空间名] [all]` | 列出任务，加 `all` 时包含已归档 |
| `/todo mine` | 查看指派给自己的任务（群聊中只含本群绑定的空间） |
| `/todo show <ref>` | 查看任务详情 |
| `/todo start <ref>` | 改为进行中 |
| `/todo done <ref>` | 改为已完成 |
| `/todo reopen <ref>` | 改回待办 |
| `/todo archive <ref>` | 改为已归档 |
| `/todo assign <ref> [@a @b]` | 整体替换负责人，留空则清除 |
| `/todo assign <ref> +@a -@b` | 增加或移除负责人 |
| `/todo edit <ref> <字段…>` | 修改标题、截止时间、优先级、标签 |
| `/todo desc <ref> [全文]` | 设置描述，留空则清除 |
| `/todo delete <ref>` | 删除任务 |

**空间与群指令**

| 指令 | 说明 |
|---|---|
| `/todo spaces` | 列出本群绑定的空间，标出默认空间和自己的当前空间 |
| `/todo use <空间名>` | 切换自己的当前空间 |
| `/todo default <空间名>` | 修改本群的默认空间 |
| `/todo space new <名字>` | 新建空间，绑定到本群，并切换为自己的当前空间 |
| `/todo space rename <新名字>` | 重命名当前空间 |
| `/todo space delete <空间名> [确认码]` | 删除空间，需在 60 秒内二次确认 |
| `/todo invite` | 重置当前空间的邀请码，旧码失效 |
| `/todo share [on\|off\|reset]` | 查看、开启、关闭或重置当前空间的公开看板链接（空间管理员）。公开看板服务未开启时，指令会提示需要管理员先开启 |
| `/todo join <邀请码>` | 把本群绑定到邀请码对应的空间 |
| `/todo leave <空间名>` | 解除本群与该空间的绑定 |
| `/todo claim` | 认领当前无主空间 |
| `/todo admin +@x` / `/todo admin -@x` | 任命或撤销当前空间的管理员（空间所有者或 AstrBot 管理员）。也可写用户 ID（如 QQ 号）：`+用户ID` / `-用户ID`，可与 @ 混用，一次最多 20 人；新增的 ID 必须已是空间成员，或在本群成员列表里 |

**任务字段写法**（`add` 和 `edit` 通用，顺序不限）

| 写法 | 含义 |
|---|---|
| `@某人` | 负责人，可以 @ 多人 |
| `11-05`、`2026-11-05`、`今天`、`明天`、`后天`、`周一`到`周日` | 截止日期，后面可接 `18:00` 这样的时间；只写日期时默认 23:59 |
| `!高`、`!中`、`!低` | 优先级 |
| `[标签]` | 添加标签 |
| 其余文字 | 标题；用双引号括起来时，里面的内容按字面理解 |

`edit` 中可以用 `无截止`、`!无`、`[-标签]` 清除截止时间、优先级或移除标签。`edit` 中写 `@某人` 会被拒绝，请改用 `assign`。

## LLM 对话管理

在群里 @ 机器人或唤醒机器人后，可以用自然语言让它操作任务。例如“帮我把周报任务指派给张三，明天中午前截止”。

**可以做的事**：

- 创建任务，设置负责人、截止时间、优先级、标签和描述。
- 查询当前空间的任务，或查询指派给自己的任务。
- 修改任务的状态、标题、截止时间、优先级、标签、描述和负责人。
- 列出本群绑定的空间，切换自己的当前空间。
- 把本群成员全部登记为空间成员（同步群成员）。需要你明确提出，机器人不会在找不到人时自己去同步。只有空间所有者、空间管理员和 AstrBot 管理员能让机器人这样做，只支持 QQ 群；已有成员的角色不变，也不会移除任何人，但昵称会更新为当前的群名片。

**不能做的事**：

- 删除任务。
- 创建、删除空间，绑定或解绑群，生成邀请码，管理管理员。

写操作（创建、修改任务，切换空间，同步群成员）只在你主动唤醒机器人的那一轮执行。机器人自己插话时，只能读取，不能写入。

**按名字指派负责人** 时，机器人按以下顺序匹配：

1. 本条消息里 @ 的人。
2. 空间成员的昵称（完全匹配，忽略大小写）。
3. 群聊中，当前群成员的群名片或账号昵称（完全匹配，只支持 QQ 群）。匹配到的人会自动成为空间成员。

如果同名的人有多个，机器人不会猜测，会要求你直接 @ 对方。想确保指派给正确的人，请直接 @ 对方。

## 配置项

在 AstrBot 插件页面中修改：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 时区 | `Asia/Shanghai` | IANA 时区名，用于解析和显示截止时间。填写无效时回退到 `Asia/Shanghai` |
| 到期提醒提前量（分钟） | `60` | 在截止时间前多少分钟提醒，`0` 表示到点才提醒。每个任务只提醒一次，修改截止时间后会重新计算 |
| 完成后自动归档天数 | `7` | 任务完成满这么多天后自动转为已归档，`0` 表示关闭 |
| 开启公开看板服务 | 关闭 | 开启后插件单独监听一个端口，提供只读看板页面 |
| 公开服务监听地址 | `127.0.0.1` | 默认只允许本机访问，建议放在反向代理后面 |
| 公开服务端口 | `6200` | Docker 部署时需要映射这个端口 |
| 对外访问地址 | 空 | 访客打开看板用的地址，例如 `https://todo.example.com`，必须以 http:// 或 https:// 开头；不填就无法生成链接 |
| 公开服务限流（每 IP 每分钟请求数） | `60` | 只统计看板数据请求，页面每 30 秒刷新一次 |
| 信任反向代理 | 关闭 | 放在反向代理后面时开启，用于按访客真实 IP 限流 |

公开看板相关的配置在插件加载时读取，修改后需要重载插件。

## WebUI 管理页

在 AstrBot 的插件页面中打开本插件的管理页。管理页由 AstrBot 管理员使用，可以：

- 浏览所有空间，包括未绑定任何群的空间。
- 在看板上拖拽改变任务状态，编辑或删除任务。
- 管理空间的群绑定、成员角色和邀请码。
- 开启、重置或关闭空间的公开链接，复制链接。
- 查看任务和空间的操作日志。
- 从群同步成员：把空间所绑定群的成员全部登记为空间成员。

“从群同步成员”目前只支持 QQ（aiocqhttp 适配器）。其他平台无法拉取群成员列表，只能通过 @ 登记成员。

## 公开看板

开启后，拿到链接的人可以在浏览器里只读查看空间的看板，无需登录。

**访客能看到的内容**：任务标题、状态、负责人昵称、截止时间、标签、优先级和描述。不显示用户 ID、创建人、群信息和操作日志，已归档任务也不显示。页面每 30 秒自动刷新。负责人没有可显示的昵称时，显示“未知成员”。

**开启方法**：

1. 在插件配置中开启公开看板服务，并填写对外访问地址。
2. 重载插件。
3. 在群里发送 `/todo share on`，或在 WebUI 管理页的空间设置里开启。
4. 把链接发给需要的人。

**撤销与关闭**：

- `/todo share reset` 让旧链接立即失效，并生成新链接。
- `/todo share off` 关闭分享。
- 删除空间后，链接立即失效。

### 部署建议

推荐保持监听 `127.0.0.1`，用 nginx、Caddy 等反向代理对外提供 HTTPS，并在“对外访问地址”里填写代理的地址。nginx 配置示例：

```nginx
location /b/ {
    proxy_pass http://127.0.0.1:6200;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    access_log off;  # 链接里带有访问凭据，不要记进访问日志
}
```

- 开启“信任反向代理”后，插件只在请求来自本机或内网地址时才采用代理转发的访客 IP。只有一层反向代理时限流才准确；前面再套 CDN 时，所有访客可能共用一个限流额度。
- 不建议把监听地址改成 `0.0.0.0` 直接对公网开放。插件本身不处理慢速连接攻击，请交给反向代理处理（例如 nginx 的 `client_header_timeout`、`limit_conn`）。
- Docker 部署：在 compose 里为 AstrBot 容器多映射一个端口（例如 `6200:6200`），并把监听地址改成 `0.0.0.0`，让容器外的反向代理能访问。端口映射时建议只绑定到宿主机本地，例如 `127.0.0.1:6200:6200`。

## 注意事项与已知限制

- **指派对象**：要确保任务指派给正确的人，请使用 @ 或用户 ID。按名字指派依赖成员自己设置的群名片或昵称，可能匹配到同名的人，或者匹配不到改过名的人。空间里已登记的名字优先于群名片，有人把自己的名字改成和别人一样时，按名字指派可能指给他。
- **成员只增不减**：退出群的人仍保留在空间成员中，包括他原来的管理员角色。目前没有移除成员的功能。“从群同步成员”会把群里其他机器人账号也登记为成员。
- **群成员缓存**：QQ 群成员列表可能有缓存，刚退群的人在短时间内仍会被视为群成员。
- **WebUI 同步的限制**：
  - 只支持 QQ（aiocqhttp）。
  - 多账号反向 WebSocket 的部署下，同步会失败。
  - 开启 AstrBot 的会话隔离（`unique_session`）时，同步会失败。
  - Telegram 等平台无法拉取群成员，只能 @。
- **批量指派**：能触发 LLM 的群成员，可以通过自然语言让机器人一次指派并 @ 最多 20 人。
- **插件级 API Key**：AstrBot 为插件生成的 API Key 拥有本插件 WebUI 接口的完整管理权限，请按管理员凭据保管，不要分享给他人，也不要写入公开的配置或代码。
- **卸载后的接口**：卸载插件后，WebUI 接口的路由不会被注销，访问时只会返回“服务未就绪”，不会读写任何数据。
- **与 astrbot_plugin_wakepro 同时使用**：wakepro 只在自己启动时记录一次指令列表。如果先启动 wakepro、再安装 teamtodo，并且 wakepro 开启了“艾特别人时不唤醒”，带 @ 的 `/todo` 指令会被拦截。安装 teamtodo 后，重载一次 wakepro 即可。
- **数据存储**：数据保存在 AstrBot 数据目录下本插件的数据文件夹中，文件名为 `teamtodo.db`（SQLite 数据库）。备份时请一并备份该文件夹。
- **公开链接**：拿到链接的人都能查看看板，请只发给需要的人。链接会出现在浏览器历史和反向代理日志里；机器人回复的链接也会写进 AstrBot 日志，分享日志或截图前请先用 `/todo share reset` 换一个新链接。
